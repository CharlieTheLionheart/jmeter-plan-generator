## ADDED Requirements

### Requirement: Generate JMeter TestPlan XML structure
The system SHALL generate a valid JMeter TestPlan XML structure.

#### Scenario: Generate basic TestPlan element
- **WHEN** generating a JMeter test plan
- **THEN** the system SHALL generate a `<TestPlan>` element with required attributes
- **THEN** the system SHALL generate a `<hashTree>` element for the TestPlan

#### Scenario: Generate TestPlan with variables
- **WHEN** the test configuration defines connection parameters
- **THEN** the system SHALL generate `<Arguments>` elements for each parameter
- **THEN** each variable SHALL have a name (e.g., `${db_url}`) and a default value

### Requirement: Generate SetupThreadGroup for DDL execution
The system SHALL generate a SetupThreadGroup for executing DDL statements.

#### Scenario: Generate SetupThreadGroup for DDL
- **WHEN** DDL statements are available for a database
- **THEN** the system SHALL generate a `SetupThreadGroup` with a single thread
- **THEN** the system SHALL generate a `JDBCSampler` for each DDL statement
- **THEN** each JDBCSampler SHALL reference the `${db_url}` variable

#### Scenario: Generate JDBCSampler for CREATE DATABASE
- **WHEN** a CREATE DATABASE DDL statement is available
- **THEN** the system SHALL generate a JDBCSampler with the DDL as the query
- **THEN** the system SHALL set the JDBC sampler to auto-commit mode

#### Scenario: Generate JDBCSampler for CREATE TABLE
- **WHEN** a CREATE TABLE DDL statement is available
- **THEN** the system SHALL generate a JDBCSampler with the DDL as the query
- **THEN** the system SHALL set the JDBC sampler to auto-commit mode

### Requirement: Generate SetupThreadGroup for shared memory initialization
The system SHALL generate a SetupThreadGroup and integrate shared memory loaders generated by `shared-memory-initializer` module.

#### Scenario: Generate SetupThreadGroup for shared memory
- **WHEN** row seed data aggregates are generated for tables
- **THEN** the system SHALL generate a `SetupThreadGroup` with a single thread
- **THEN** the system SHALL execute before all other thread groups

#### Scenario: Integrate shared memory loaders from shared-memory-initializer
- **WHEN** a table has a row seed data aggregate file
- **THEN** the system SHALL call `shared-memory-initializer` to generate `JSR223PreProcessor` components
- **THEN** the system SHALL insert the generated components into the SetupThreadGroup
- **THEN** the script SHALL load the CSV file and store the data in JMeter shared memory

### Requirement: Generate write thread groups
The system SHALL generate one write thread group per time-series table.

#### Scenario: Generate thread group for table
- **WHEN** a time-series table has write configuration
- **THEN** the system SHALL generate a `ThreadGroup` for the table
- **THEN** the thread group SHALL have `num_threads` threads
- **THEN** the thread group SHALL run for `${test_duration}` seconds

#### Scenario: Set thread group loop count
- **WHEN** generating a thread group
- **THEN** the system SHALL set the loop count to infinity (`-1`)
- **THEN** the system SHALL use `duration` to control test duration

### Requirement: Generate query thread groups
The system SHALL generate one query thread group per query configuration.

#### Scenario: Generate thread group for query
- **WHEN** a query configuration is defined
- **THEN** the system SHALL generate a `ThreadGroup` for the query
- **THEN** the thread group SHALL have `num_threads` threads (default 1)
- **THEN** the thread group SHALL run for `${test_duration}` seconds

#### Scenario: Place empty JDBC sampler placeholder
- **WHEN** generating a query thread group
- **THEN** the system SHALL place a placeholder `JDBCSampler` element
- **THEN** the placeholder SHALL be filled by the query functionality module

### Requirement: Generate JMX file
The system SHALL output the complete test plan as a JMX file.

#### Scenario: Output JMX file
- **WHEN** all JMX elements are generated
- **THEN** the system SHALL output a `.jmx` file
- **THEN** the file SHALL be valid XML and readable by JMeter 5.5+

### Requirement: Handle thread group ordering
The system SHALL ensure thread groups execute in the correct order.

#### Scenario: SetupThreadGroups execute first
- **WHEN** generating all thread groups
- **THEN** all `SetupThreadGroup` elements SHALL appear before regular thread groups in the JMX
- **THEN** the SetupThreadGroup for shared memory SHALL appear after the SetupThreadGroup for DDL

#### Scenario: Write thread groups before query thread groups
- **WHEN** generating write and query thread groups
- **THEN** all write thread groups SHALL appear before query thread groups in the JMX
